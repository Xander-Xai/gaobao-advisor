## 1. 公众号搭建指南

### 1.1 账号类型选择

| 对比项 | 订阅号 | 服务号 |
|--------|--------|--------|
| **认证门槛** | 个人即可注册，0成本 | 需营业执照，年审300元 |
| **推送频率** | 每天1次 | 每月4次 |
| **消息位置** | 订阅号消息列表 | 聊天列表（更醒目） |
| **自定义菜单** | ✅ 支持 | ✅ 支持 |
| **自动回复** | ✅ 支持 | ✅ 支持 |
| **模板消息** | ❌ 不支持 | ✅ 支持 |
| **微信支付** | ❌ 不支持 | ✅ 支持 |
| **适合场景** | 内容输出、用户教育 | 交易、服务通知 |

**推荐：订阅号（个人）**

理由：
- OPC创始人无需营业执照，0元起步
- 高考季内容密集，每天推送1次正好匹配高频内容需求
- 后续流量起来后可迁移至服务号（已有内容沉淀）
- 订阅号的消息被折叠不影响——因为核心转化路径是「内容 → 加微信群」而非「公众号直接变现」

### 1.2 注册步骤

1. 打开 `mp.weixin.qq.com`，点击「立即注册」
2. 选择「订阅号」
3. 使用未绑定过公众号的邮箱注册（建议用专用邮箱：`gaobao-advisor@xxx.com`）
4. 信息登记：选择「个人」类型
5. 填写身份证信息 + 微信扫码验证（运营者绑定）
6. 账号名称：**gaoBao高考顾问**
7. 完成注册，进入后台

> **注意事项：**
> - 个人订阅号名称一年只能改2次，确定后再改
> - 头像和简介修改次数无限制，但审核需1-3个工作日
