## 核心理念：开源是信任引擎，不是放弃商业

**开源 ≠ 免费劳动。开源 = 用代码建立信任，用服务创造收入。**

全球最成功的开源一人公司案例：
- Caleb Porzio（Livewire/AlpineJS）→ GitHub Sponsors 年入 $100K+
- Theo Browne（PingPro）→ 开源工具 + YouTube → 年入 $1M+
- Matt Palmer（Shadcn 组件库）→ 开源 → 被 Vercel 收购

**你的独特优势**：张雪峰去世后留下的内容真空 + 1290万考生/年的刚需市场 + 已建成的 505 条语录 + 30 省数据壁垒。

## 一、开源策略：Open Core 模型

### 1.1 开源什么（建立信任）

| 开源内容 | 目的 | GitHub 价值 |
|---------|------|------------|
| `agent.py` 核心逻辑 | 技术展示 | Star/Fork 增长 |

| 部署指南 | 降低门槛 | 社区贡献 |

### 1.2 不开源什么（商业壁垒）

| 闭源内容 | 原因 | 商业价值 |
|---------|------|---------|
| 实时录取数据 API | 数据采集成本高 | 数据授权收入 |
| 个性化报告生成器 | 差异化功能 | 付费转化 |
| 用户行为分析系统 | 运营决策 | 优化转化率 |
| 高级提示词工程 | 效果差异 | 付费版体验 |
| 1对1咨询 SOP | 服务溢价 | 高价服务 |

### 1.3 开源带来的 5 个 OPC 赋能

| 赋能 | 机制 | 效果 |
|------|------|------|
| **信任引擎** | "我做了开源高考AI顾问，GitHub 7.6k Star" | 技术咨询报价从 ¥500 → ¥5000 |
| **内容引擎** | 每个用户对话 = 内容素材（脱敏后） | 抖音/B站日更素材不愁 |
| **人才引擎** | 开源贡献者 = 潜在合作伙伴/员工 | 一人公司也能有团队 |
| **数据引擎** | 用户使用数据（脱敏）→ 优化知识库 | 产品越用越好 |
| **品牌引擎** | GitHub 排名 + 技术博客 + 社区 | OPC 品牌背书 |

## 三、增长飞轮

```
开源 GitHub（信任）
    ↓ Star/Fork/Issue
技术博客 + 知乎（SEO）
    ↓ 搜索流量
抖音/B站/小红书（内容）
    ↓ 粉丝积累
免费 Agent 体验（获客）
    ↓ 3 次对话建立信任
付费转化（¥9.9-49.9）
    ↓ 价值感知
私域沉淀（微信社群）
    ↓ 持续触达
高价服务（¥299-4999）
    ↓ 案例沉淀
内容素材（循环）
```

### 飞轮关键节点

1. **6-7 月高考季**是爆发点 → 提前 2 个月布局内容
2. **劝退型内容最容易传播** → "这个专业别碰！" > "推荐你学 XX"
3. **每个用户对话都是内容素材** → 脱敏后用于抖音/知乎
4. **家长是最愿意为教育付费的群体** → 付费转化率高

## 八、核心原则

1. **开源是信任引擎，不是放弃商业** — 代码开源，服务收费
2. **内容先行** — 先有流量，再有产品，再有变现
3. **高考季是天然爆发窗口** — 必须提前布局
4. **一人公司杠杆** — 一套架构复用 5-10 个垂直场景
5. **PMF 优先** — 先验证需求，再投入开发
6. **人格即壁垒** — "敢说真话"比任何技术都难复制
7. **数据是护城河** — 30 省 13000+ 条分数线，竞品追不上
8. **Agent 做 80%，人做 20%** — AI 降低边际成本，人提供信任溢价
