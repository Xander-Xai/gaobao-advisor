## 一、三种高考模式详解

### 1. 3+3 模式（上海、浙江、北京、天津、山东、海南等）

| 项目 | 内容 |
|------|------|
| **必考** | 语文 + 数学 + 英语（各150分） |
| **选考** | 从物理/化学/生物/历史/地理/政治（思想政治）中选3门 |
| **满分** | 750分（上海660分） |
| **赋分制** | 选考科目按排名赋分，每门满分100分 |
| **选科组合数** | C(6,3) = **20种组合** |

> 核心特点：选科最自由，但也最容易选错。没有物理+化学的组合，会损失大量工科和医学专业。

### 2. 3+1+2 模式（广东、江苏、湖北、湖南、河北、辽宁、福建、重庆等大部分省份）

| 项目 | 内容 |
|------|------|
| **必考** | 语文 + 数学 + 英语（各150分） |
| **首选（1）** | 从物理 / 历史中选1门（原始分计入，满分100分） |
| **再选（2）** | 从化学/生物/地理/政治中选2门（赋分制，各100分） |
| **满分** | 750分 |
| **选科组合数** | **12种组合**（6种物理方向 + 6种历史方向） |

> 核心特点：物理和历史二选一相当于传统文理分科的升级版。选物理 = 理工方向为主，选历史 = 文史方向为主。

### 3. 传统文理分科模式（部分省份仍保留或过渡中）

| 项目 | 内容 |
|------|------|
| **文科** | 语数英 + 政治 + 历史 + 地理 |
| **理科** | 语数英 + 物理 + 化学 + 生物 |
| **特点** | 没有选择余地，全国统一模式 |

> 2026年仍在使用传统模式的省份极少，基本已全面过渡到新高考。

## 六、常见选科误区——5个坑

### 坑1：选"看起来简单"的科目

> "地理比化学简单，我选地理吧"

**真相：** 新高考选科不是选简单的，而是选"收益最大"的。化学虽然难，但能多覆盖10%的专业。地理虽然简单，但很多工科和医学专业不认。

**正确做法：** 除非你的目标是纯文方向（法学/教育/新闻），否则尽量保化学。

### 坑2：跟着好朋友选

> "我好朋友都选了物生地，我也选这个"

**真相：** 选科影响的是你未来6年的走向（本科+研究生），不是高中两年的社交。好朋友不在同一个组合，高考后自然会分散。

**正确做法：** 按自己的目标和优势选，社交可以通过其他方式维系。

### 坑3：老师说你适合XX就盲从

> "班主任说我物理不好，建议我学历史方向"

**真相：** 班主任的判断往往基于当前成绩排名，但高二高三物理还有很大提升空间。而且"物理方向招生计划多、录取分数相对低"，放弃物理可能损失更多机会。

**正确做法：** 物理目前排名前50%，建议坚持。排名后30%，可考虑转历史方向。

### 坑4：认为"政治/地理没用"

> "政治地理不学也行，高考不考这几科我不管"

**真相：** 如果你未来想考公务员、选调生、军队文职，政治是隐性刚需。高考志愿中，公安学类、部分法学类明确要求选考政治。

**正确做法：** 有考公打算的，考虑物化政组合，一箭双雕。

### 坑5：忽视"赋分制"的博弈效应

> "我生物考了85分，排名靠前，赋分肯定高"

**真相：** 赋分制看的是你在全省的排名百分比，不是原始分。如果选生物的都是尖子生，你的85分可能只赋到75分。而选地理的"分母"更大，同样的排名可能赋到更高的分数。

**正确做法：** 了解各科选考人数和竞争分布，选择"赋分红利"更大的科目。

## 七、分场景推荐：你的目标决定你的选科

### 想学医

| 推荐组合 | 说明 |
|---------|------|
| **物化生** | 最优选，覆盖所有医学院校要求 |
| 物化政 | 次选，放弃生物但保留核心要求 |
| 物生地 | 仅限部分院校，临床医学受限严重 |

> 关键提醒：2026年越来越多医学院要求"物理+化学+生物"三选。选了物化生不会错。

### 想学计算机/人工智能

| 推荐组合 | 说明 |
|---------|------|
| **物化生** | 覆盖所有计算机类专业 |
| **物化地** | 同上，地理可能对考研有帮助 |
| 物化政 | 可行，但编程思维靠课外培养 |

> 计算机专业只要求物理，但物理+化学能覆盖更多交叉学科（如生物信息学、AI+医学等）。

### 想考公务员/事业编

| 推荐组合 | 说明 |
|---------|------|
| **物化政** | 物理保工科选择，政治保考公选择 |
| **史化政** | 纯文科路线，法学/汉语言/政治学 |
| 史地政 | 传统文科，法学/教育学为主 |

> 关键提醒：招录人数最多的公务员岗位集中在法学、财会、汉语言文学、计算机。选政治不是为了考公那几道题，而是部分岗位要求"政治学类"专业。

### 想进国家电网/央企

| 推荐组合 | 说明 |
|---------|------|
| **物化生** | 电气工程及其自动化首选 |
| **物化地** | 同上，可覆盖能动、自动化等 |
| 物化政 | 可行，但电力类岗位偏理工 |

> 国家电网校招核心专业：电气工程、能源与动力工程、自动化、通信工程。全部要求物理+化学。

### 想学金融/经济

| 推荐组合 | 说明 |
|---------|------|
| **物化生** | 数学+物理基础对量化金融有优势 |
| 物化地 | 同上 |
| 史化政 | 传统文科路线也能学金融，但量化方向受限 |

> 金融行业正在量化转型，有物理+数学基础的毕业生更受欢迎。

### 想当老师

| 推荐组合 | 说明 |
|---------|------|
| **史化政** | 文科师范方向最优 |
| **物化生** | 理科师范方向最优 |
| 史地政 | 语文/历史/政治老师方向 |

> 关键提醒：如果你打算当数学/物理/化学老师，必须选对应的理科组合。想当语文/英语老师，历史方向即可。

## 八、一句话总结：不同目标的最优选科组合

| 你的目标 | 最优组合 | 备选组合 | 一句话理由 |
|---------|---------|---------|-----------|
| 想学临床医学 | **物化生** | 物化政 | 医学院校的硬性门槛 |
| 想学计算机/AI | **物化生** | 物化地 | 物理是核心，化学拓宽边界 |
| 想进电网/央企 | **物化生** | 物化地 | 电气类专业的标准配置 |
| 想考公务员 | **物化政** | 史化政 | 物理保工科，政治保考公 |
| 想学法学 | **史化政** | 史地政 | 法学不限选科，但政治有优势 |
| 想当老师 | **史化政** / **物化生** | 看学科方向 | 教什么就选什么 |
| 想学金融 | **物化生** | 物化地 | 量化金融需要理科基础 |
| 不确定方向 | **物化生** | — | 覆盖率最高，给自己留最多选择 |
| 物理实在不行 | **物化政** | 物生政 | 至少保住化学 |
| 纯文科倾向 | **史化政** | 史地政 | 保留最大灵活性 |

> **最终忠告：** 如果你现在完全不确定未来要做什么，选 **物理+化学** 就对了。这个组合不会封死任何方向，但你一旦放弃了物理或化学，可能在未来填报志愿时发现"想报的专业报不了"。给自己留余地，是选科最大的智慧。
