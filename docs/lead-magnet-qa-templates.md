# 高考志愿提问模板

### 这样问最准——12个模板让AI秒懂你的需求

> 由 **gaoBao AI 高考志愿顾问** 精心整理
> 使用本模板向 AI 提问，获得最精准的志愿建议

---

## 使用说明

每个模板都经过反复测试，能引导 AI 给出**结构化、可执行**的建议。使用方法：

1. 从下方选择最贴合你需求的模板
2. 将 **【】** 中的占位内容替换为你的真实信息
3. 复制粘贴发送给 AI，等待个性化建议
4. 沿着 AI 的追问继续深入，效果更佳

> 提示：信息越完整，AI 回答越精准。不确定的内容可以写"不确定"，AI 会帮你分析。

## 模板一：完整信息模板（最全面）

**适用场景：** 刚开始填报，想要一份完整的志愿方案

```
我的基本情况：
- 高考省份：【省份，如广东】
- 选科模式：【3+3 / 3+1+2 / 传统文理】
- 选科组合：【如物化生 / 物化政】
- 高考总分：【分数】
- 省排名（位次）：【位次，如不确定可写"预估XXX"】
- 各科成绩：语文【】/ 数学【】/ 英语【】/ 选科1【】/ 选科2【】/ 选科3【】

我的偏好：
- 地域偏好：【想去的城市或"不限"】
- 院校层次：【985 / 211 / 双一流 / 普通本科 / 都可以】
- 专业方向：【感兴趣的方向，如"计算机相关"或"不确定"】
- 家庭情况：【普通家庭 / 行业资源 / 经济需考量 / 其他】
- 特殊条件：【是否党员/团员、身体条件限制、军校/公安意向等，没有可写"无"】

请给我一份包含冲刺、稳妥、保底各3-5所院校的志愿方案，每个方案注明专业和录取概率。
```

**为什么这个模板有效：** AI 需要分数、位次、选科三个核心数据才能匹配录取概率。省份决定了招生计划和分数线体系，院校层次和地域偏好帮助 AI 缩小筛选范围。一次性给出全部信息，省去多轮追问。

**示例 AI 输出：**
> 根据你的信息（广东物理类，物化生，628分/位次18500），建议如下：
> - 冲刺：华南理工大学（计算机类，往年位次17000-19000，概率45%）
> - 稳妥：暨南大学（软件工程，位次20000-22000，概率80%）
> - 保底：深圳大学（计算机科学与技术，位次25000+，概率95%）

## 模板二：不知道学什么（先理方向）

**适用场景：** 成绩出来了，但完全没有方向感

```
我是【省份】考生，高考【分数】分，省排名【位次】。
选科是【选科组合】。

说实话我不知道自己想学什么，也没有特别的爱好。
我的情况是：【写几句你平时的偏好，比如"喜欢动手""不排斥数学""讨厌背诵""喜欢和人打交道"】
家庭情况：【父母职业/家里有什么资源/经济情况】

请帮我分析 3-5 个适合我的专业方向，每个方向说清楚：
1. 这个方向是干什么的
2. 将来的就业和收入大概是什么水平
3. 以我的分数能去什么层次的学校
```

**为什么这个模板有效：** AI 最怕收到"帮我选志愿"这种没有锚点的请求。用生活化的偏好描述（而非专业名词）帮 AI 建立你的用户画像，AI 能据此推荐匹配度更高的方向。要求 AI 给出"就业+收入"数据，避免被冷门专业忽悠。

**示例 AI 输出：**
> 根据你"喜欢动手、不排斥数学、喜欢和人打交道"的描述，推荐以下方向：
> 1. **电子信息工程** — 偏硬件+沟通，华为/中兴等大厂需求大，应届平均月薪8-12K
> 2. **数据科学** — 数据分析+业务沟通，各行各业都需要，门槛适中
> 3. **医学影像技术** — 动手操作设备+与患者沟通，三甲医院稳定就业

## 模板三：有目标了让AI评估

**适用场景：** 已经有明确专业方向，需要评估可行性

```
我的基本情况：【省份】【分数】【位次】
选科：【选科组合】

我想学【专业名称/方向】，原因是【说说为什么想学这个】。

请帮我评估：
1. 以我的分数，这个专业能去哪些学校？列出冲刺/稳妥/保底
2. 这个专业真实的就业情况怎么样？不要说套话
3. 这个专业在哪些学校性价比最高？
4. 有没有类似的替代专业可以同时考虑？
```

**为什么这个模板有效：** 先表明目标再让 AI 评估，AI 的回答会更聚焦。"不要说套话"这句话会迫使 AI 给出真实数据而非招生宣传话术。"替代专业"帮你拓展备选方案，防止一条路走到黑。

**示例 AI 输出：**
> 关于临床医学（5年制）：
> 1. 以你的605分（广西位次32000），冲刺：广西医科大学；稳妥：桂林医学院；保底：右江民族医学院
> 2. 真实就业：本科毕业进三甲困难，多数需要考研；县级医院好进但收入有限（5-8K）；建议确认是否愿意读研5-8年
> 3. 性价比最高：温州医科大学（眼视光）、哈尔滨医科大学（影像）

## 模板四：几个选项纠结中

**适用场景：** 在2-3个专业/学校之间犹豫不决

```
我分数【分数】，位次【位次】，省份【省份】，选科【选科组合】

我现在纠结这几所/几个：
选项A：【学校/专业1】
选项B：【学校/专业2】
选项C：【学校/专业3，没有可省略】

我纠结的原因是：【说说你的顾虑，比如"学校好但专业冷门""专业好但学校一般""家里人意见不统一"】

请从以下维度帮我对比分析：
- 录取把握
- 就业前景
- 考研/深造空间
- 性价比
- 给出你的最终推荐和理由
```

**为什么这个模板有效：** 把纠结原因说清楚，AI 才能针对性地帮你做决策。"最终推荐"强制 AI 给出结论，而不是罗列一堆废话让你更纠结。

**示例 AI 输出：**
> 三选一分析：
> | 维度 | A 武汉理工·土木 | B 长安大学·交通 | C 河海大学·水利 |
> | 录取把握 | 70% | 85% | 75% |
> | 就业前景 | 建筑行业下行 | 新基建有政策利好 | 水利投资稳中有升 |
> | 考研空间 | 转方向较易 | 本校读研方便 | 跨考自由 |
> | **推荐** | ⭐ 不推荐 | ✅ 首选 | 可考虑 |

## 模板五：专科/低分段求生存

**适用场景：** 分数不理想，需要务实的升学+就业路线

```
我是【省份】考生，高考【分数】分，位次【位次】。
选科是【选科组合】，分数上本科比较困难/只能上民办本科。

我的实际情况：
- 家庭经济：【能负担/较紧张/需要自力更生】
- 动手能力：【较强/一般】
- 愿不愿意复读：【愿意/不愿意】
- 地域偏好：【有/无】

请给我务实的建议：
1. 是选择专科还是民办本科？分析利弊
2. 如果走专科，哪些专业就业好、可以专升本？
3. 给出 3-5 个具体的学校+专业推荐
4. 专升本的路径和难度如何？
```

**为什么这个模板有效：** 低分段最忌讳被"名校情怀"误导。这个模板引导 AI 从就业和升学路径给出务实方案。"经济情况"和"动手能力"这两个维度，能帮 AI 判断适合技能型还是学术型路径。

**示例 AI 输出：**
> 400分广东物理类，建议专科优先：
> 1. 选广东轻工职业技术学院的"智能控制技术"，就业率95%+，专升本率约40%
> 2. 避开工商管理、市场营销等万金油专业
> 3. 专升本难度中等，大一开始准备，成功率可观
> 4. 比读民办本科（学费2万+/年）性价比更高

## 模板六：高一选科咨询

**适用场景：** 高一学生面临新高考选科决策

```
我是【省份】高一学生，所在学校是【学校类型：省重点/市重点/普通高中】。

我的成绩情况（大致排名）：
- 语文/历史/政治：年级前【】%
- 数学/物理/化学：年级前【】%
- 英语：年级前【】%
- 其他科目：【简述】

我的初步想法：【如"想学工科但物理一般"或"没有明确方向"】
家里的情况：【父母建议/行业资源/无特别要求】

请帮我：
1. 分析适合我的选科组合
2. 这个组合能覆盖哪些专业方向
3. 给出明确的建议和理由
```

**为什么这个模板有效：** 选科决定未来三年的学习难度和志愿覆盖面。提供年级排名百分比比原始分更有参考价值（不同学校考试难度不同）。"初步想法"帮 AI 判断你是否需要方向引导。

## 模板七：家里有行业资源怎么利用

**适用场景：** 家里在特定行业有关系或资源

```
我是【省份】考生，【分数】分，位次【位次】，选科【选科组合】。

家里的情况：我【父亲/母亲/亲戚】在【行业/单位名称】工作/有一定资源。

我的考虑是：【想利用这些资源 / 想看看有没有捷径 / 想避开这个方向】

请帮我分析：
1. 如果想利用这个资源，我应该学什么专业、去什么学校？
2. 这条路的门槛和要求是什么？（比如是否需要特定院校、是否需要考公/考编）
3. 如果不走这条路，我还有什么好的选择？
4. 诚实评估：这个资源的实际价值有多大？值不值得围着它选？
```

**为什么这个模板有效：** 有行业资源是真实优势，但很多人不知道怎么最大化利用。AI 可以帮你分析"资源变现"需要的专业和学历门槛。最后一问强迫 AI 给出诚实评估，避免高估或低估资源价值。

**示例 AI 输出：**
> 父亲在国家电网工作：
> 1. 电气工程及其自动化是首选，华北电力大学是"电网亲儿子"
> 2. 门槛：一本以上 + 电气专业 + 英语四级 + 身体条件合格
> 3. 替代选择：能源与动力工程、自动化（也能进电网）
> 4. 资源评估：国网校招竞争激烈，内推可加分但不能决定一切；电气专业即使不进电网，就业也很好

## 模板八：考公/考编方向

**适用场景：** 以公务员或事业编为职业目标

```
我是【省份】考生，【分数】分，位次【位次】，选科【选科组合】。

我的职业目标：考公务员/事业编（【国考/省考/选调生/军队文职，选一个或多个】）

请帮我规划：
1. 哪些专业考公/考编的岗位最多、竞争最小？
2. 推荐 3-5 个适合的学校+专业
3. 选调生对学校和身份有什么要求？
4. 这条路的利弊分析
```

**为什么这个模板有效：** 考公有明确的"专业目录"限制，不同专业能报的岗位数量差距巨大。AI 可以帮你筛选"招录比最优"的专业方向。明确考试类型帮 AI 聚焦到具体路径。

**示例 AI 输出：**
> 考公热门专业排名（岗位数量）：
> 1. 法学 — 每年招录万人以上，法检系统刚需
> 2. 财会/审计 — 财政局、审计局、税务局大量需求
> 3. 计算机 — 数字政府建设，需求逐年增长
> 4. 汉语言文学 — 综合岗适配度高
> 注意：选调生限定双一流+党员+学生干部，如果目标选调，学校层次优先

## 模板九：考研择校

**适用场景：** 高考志愿要考虑未来考研路径

```
我是【省份】考生，【分数】分，位次【位次】，选科【选科组合】。

我本科毕业后打算考研，目标方向是【目标专业/研究方向】。

请帮我倒推：
1. 考这个方向的研究生，本科应该学什么专业？
2. 哪些本科学校保研率高 / 考研氛围好？
3. 以我的分数能去什么层次的学校？给出推荐
4. 本科阶段需要做什么准备？
```

**为什么这个模板有效：** "以终为始"的策略帮 AI 做逆向规划。保研率是隐藏信息——很多"双非"学校保研率不到5%，而部分211保研率超过15%，选择直接影响升学难度。

## 模板十：新高考省份选科

**适用场景：** 新高考省份考生，想了解选科对志愿的影响

```
我是【省份】考生，新高考【3+3 / 3+1+2】模式。

我的选科组合是【组合，如物化政】
高考【分数】分，位次【位次】

请帮我分析：
1. 我这个组合能报哪些专业？有没有限制？
2. 哪些热门专业我报不了？（比如临床医学要求物化必选吗？）
3. 如果想拓宽选择面，有没有更好的组合？
4. 我这个组合的竞争对手多不多？
```

**为什么这个模板有效：** 新高考选科直接决定了你能报的专业范围。很多家长不知道"物理+化学"组合才能覆盖90%以上的工科和医学专业。提前了解限制，避免志愿填报时才发现选科不够用。

## 模板十一：分数线刚出来紧急咨询

**适用场景：** 出分后黄金48小时，需要快速决策

```
紧急！我是【省份】考生，刚刚出分。

分数：【分数】
位次：【位次】
选科：【选科组合】

时间紧迫，请快速给我：
1. 根据我的分数，最值得冲的 3 所学校
2. 最稳的 3 所学校
3. 最安全的 3 所学校
4. 一个提醒：这个分数段最容易踩的坑是什么？

请直接给结论，不需要详细分析。
```

**为什么这个模板有效：** 出分后信息爆炸期，家长和考生最需要的是"直接给结论"。提前准备好分数和位次，第一时间发送，AI 可以在几秒内给出结构化建议，比翻书查数据快几十倍。

## 模板十二：跟父母意见不合怎么办

**适用场景：** 考生和家长在志愿选择上有分歧

```
我现在遇到一个家庭分歧：

我的想法：想学【你的选择，如"游戏设计"】
父母的想法：希望我学【他们的选择，如"临床医学"】
分歧的核心：【说说你们各自的理由】

我的分数：【分数】，位次【位次】，省份【省份】，选科【选科组合】

请帮我们分析：
1. 我想学的方向，真实的就业前景到底怎么样？（不要美化也不要吓人）
2. 父母建议的方向，以我的分数能去什么学校？
3. 有没有折中方案，既能学到我喜欢的，又有不错的就业？
4. 给一个中立的建议：你们觉得我们应该怎么决策？
```

**为什么这个模板有效：** 把分歧原委交给AI，AI 作为"第三方"可以给出不带情绪的分析。要求"不美化也不要吓人"避免AI为了讨好任何一方而失真。"折中方案"是这类场景最需要的输出。

## 附录：提问技巧速查

| 技巧 | 说明 |
|------|------|
| 一定给位次 | 分数会波动，位次才是硬通货 |
| 说清省份 | 不同省份的招生计划和分数线完全不同 |
| 明确选科 | 选科决定了你报专业的门槛 |
| 给出偏好 | "不限"也比不写好，AI 会帮你缩小范围 |
| 要求结论 | 写"给结论/给推荐"，AI 不会只罗列信息 |
| 多轮追问 | 第一轮要方案，第二轮要细节，效果最好 |
