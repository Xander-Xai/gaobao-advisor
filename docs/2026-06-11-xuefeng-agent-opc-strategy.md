## 三、增长飞轮

```
免费Agent引流 → 用户使用 → 案例沉淀 → 内容素材 → 短视频传播
      ↑                                                  ↓
   口碑传播 ← 社群运营 ← 付费转化 ← 粉丝积累 ← 流量增长
```

### 飞轮关键节点

1. **6-7月高考季**是爆发点——提前2个月布局内容
2. **每个用户的对话都是内容素材**（脱敏后）
3. **劝退型内容最容易传播**（"这个专业别碰" > "推荐你学XX"）
4. **家长是最愿意为教育付费的群体**

## 六、内容引擎：抖音内容矩阵

### 6.1 五种内容模板

#### 模板A：专业劝退（最容易爆）
- 格式：「XX专业，千万别碰！」
- 15-30秒，前3秒钩子+真相揭露+数据佐证+替代建议
- 来源：knowledge_base.md 第三章 + 第十章
- 可生成：20+条

#### 模板B：逆袭路径
- 格式：「只有XX分？这条路比985还稳！」
- 面向低分学生，痛点共鸣+反转+具体路径
- 来源：§14（专科策略）+ §11.3（低分好学校）
- 可生成：10+条

#### 模板C：家庭资源匹配
- 格式：「你家在XX系统？那必须选这个专业！」
- 面向家长，资源分析+具体路径+金句
- 来源：§1.3 + §13（稳定就业路径）
- 可生成：8条

#### 模板D：同名专业揭秘
- 格式：「同样是XX专业，在不同学校差距有多大？」
- 知识型，2-3个学校对比
- 来源：§3.2（同名专业差异表）
- 可生成：6条

#### 模板E：AI时代专业重评估
- 格式：「2026年了，XX专业还值得学吗？」
- 蹭热点，AI对各行业影响
- 来源：§16（2025-2026最新趋势）
- 可生成：8条

## 七、产品化技术方案

### 7.1 MVP路线（先A后B再C）

| 阶段 | 方案 | 开发周期 | 成本 |
|------|------|---------|------|
| **Phase 1** | Streamlit Web版 | 1天 | 免费(Streamlit Cloud) |

| **Phase 3** | 微信小程序 | 5-7天 | 微信云开发免费额度 |

### 7.2 Phase 1：Streamlit Web版

```
技术栈：
├── Streamlit（Python Web框架）
├── 复用agent.py核心逻辑
├── Streamlit Cloud免费托管
└── 微信可直接打开链接

功能：
├── 聊天界面（st.chat_message）
├── 欢迎页（介绍工具+使用说明）
├── 免费3次限制 + 付费升级提示
├── 侧边栏（品牌+使用技巧+付费入口）
└── 移动端自适应
```

### 7.3 数据存储方案

```
初期（0-100用户）：
├── 用户数据：SQLite
├── 对话历史：内存（不持久化）
├── 知识库：knowledge_base.md直接读取
└── 总月成本：< ¥50

中期（100-1000用户）：
├── 用户数据：PostgreSQL
├── 对话历史：Redis缓存
├── 知识库：向量化存储（pgvector）
└── 总月成本：< ¥500
```
