## 三、P1：轻量埋点系统（纯 Python + SQLite）

### 3.1 架构

```
用户操作 → tracker.log_event() → data/analytics.db (SQLite)
                                      ↓
                              /stats 命令查询统计
```

新增文件：
- `analytics/tracker.py` — 事件记录器
- `data/analytics.db` — SQLite 数据库（自动创建）

### 3.2 事件类型

| 事件名 | 触发时机 | 记录字段 |
|--------|---------|---------|
| `session_start` | 用户开始对话 | timestamp, session_id |
| `slot_filled` | 槽位被填充 | slot_type, slot_value(脱敏) |
| `query_major` | 用户问到专业 | major_name |
| `query_school` | 用户问到学校 | school_name |
| `emotion_detected` | 情绪被检测到 | level(🟢🟡🔴), score |
| `recommendation_given` | 给出冲稳保推荐 | strategy(冲/稳/保), school_count |
| `conversation_end` | 对话结束 | turn_count, duration_sec |
| `paywall_shown` | 显示付费提示 | context |
| `link_clicked` | 点击外部链接 | link_type(wechat/gongzhonghao/github) |

### 3.3 隐私保护规则

1. **不记录用户输入原文** — 只记录结构化事件
2. **省份/专业/学校名** — 公开信息，不涉及隐私
3. **情绪档位** — 只记录🟢🟡🔴，不记录触发词
4. **无用户标识** — 只有匿名 session_id（随机 UUID）
5. **数据存本地** — 不上传任何第三方服务
6. **分数/位次** — 不记录具体数值，只记录"有/无"

### 3.4 统计查询

在 agent.py 中添加 `/stats` 命令（仅限 CLI 模式，不暴露给普通用户）：

### 3.5 数据库 Schema

```sql
CREATE TABLE events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    event_type TEXT NOT NULL,
    event_data TEXT,  -- JSON
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_events_session ON events(session_id);
CREATE INDEX idx_events_type ON events(event_type);
CREATE INDEX idx_events_time ON events(created_at);
```

## 四、P2：内容引擎机制

### 4.1 热门问题统计

自动统计并输出：
- 热门专业 TOP 10（被问最多的专业）
- 热门学校 TOP 10（被问最多的学校）
- 热门省份 TOP 10（用户最多的省份）
- 情绪档位分布（🟢🟡🔴 比例）

→ 这些数据直接用于**抖音/B站内容选题**

### 4.2 金句候选收集

当 LLM 回复中检测到以下特征时，自动标记为"候选金句"：
- 回复长度 ≤ 50 字
- 包含感叹号或反问句
- 情绪档位为🟡或🔴时的回复

存入 `data/highlights.json`：
```json
[
  {
    "text": "家里没矿，别碰金融。",
    "context": "河南560分，想学金融",
    "timestamp": "2026-06-12T10:30:00",
    "emotion_level": "🟡"
  }
]
```

→ 定期人工筛选 → 抖音/小红书素材

### 4.3 对话脱敏分享（简化版）

用户完成咨询后，可选"生成分享文本"：
- 自动脱敏：省份保留，分数模糊化（"580分" → "580分左右"），删除姓名/微信号
- 生成纯文本格式（可直接粘贴到朋友圈/微信群）
- 底部带"由雪峰Agent生成 | [体验链接]"

|------|------|
