### 致命漏洞详情

**[C1] API 密钥明文泄露**
- 位置：`.env` + `.streamlit/secrets.toml`
- 问题：真实 API Key `sk-7JlJ...` 明文存储，可能已提交到 Git 历史
- 修复：立即轮换 Key + BFG 清除 Git 历史

**[C2] XSS — LLM 回复通过 unsafe_allow_html 渲染**
- 位置：`app.py:1233-1234`
- 问题：LLM 回复中非 SCHOOL_DATA 部分未转义，直接 `st.markdown(..., unsafe_allow_html=True)`
- 修复：对非 SCHOOL_DATA 内容 `html.escape()` 后再渲染

### 高危漏洞摘要

| 编号 | 漏洞 | 位置 | 修复方案 |
|------|------|------|---------|
| H1 | 侧边栏槽位信息未转义 | app.py:719 | 用 `html.escape(val)` 或 `st.text()` |

| H3 | 会话 ID 可猜测（48位） | app.py:541-543 | 改用完整 128 位 UUID4 |
| H4 | 密码明文比较（时序攻击） | app.py:605 | `hmac.compare_digest()` |
