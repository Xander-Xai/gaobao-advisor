# 工具调用模板 — 可复用模式

## 模式：工具调用格式约束

### 问题
LLM 有时会在回复中输出 XML/JSON 标签来「调用工具」，但这在纯对话场景中不可用。

### 解决方案（gaobao 采用）
```
**重要**：你是一个纯对话AI，不能使用 `<tool_call>` `<function>` 等XML标签格式。
所有回复必须是自然语言文字。
```

### 通用版本
```
**重要**：你是一个纯对话助手。禁止输出以下格式：
- `<tool_call>` / `</tool_call>`
- `<function>` / `</function>`
- JSON 代码块中的工具调用
所有回复必须是自然语言。
```
