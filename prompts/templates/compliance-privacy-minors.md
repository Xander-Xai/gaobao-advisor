# 数据隐私与未成年人保护模板

> 适用于：面向中国用户的 AI 应用，尤其涉及未成年人（<18岁）用户。基于 PIPL + 未成年人保护法 + 算法推荐管理规定。

---

## 法律依据

| 法规 | 关键条款 | 对本项目的约束 |
|:--|:--|:--|
| 《个人信息保护法》(PIPL) | 第28条、第31条 | 未满14岁需监护人单独同意；14-18岁增强保护 |
| 《未成年人保护法》 | 第75条 | 防沉迷、内容过滤、不得诱导消费 |
| 《儿童个人信息网络保护规定》 | 第9-16条 | 指定专人负责、最小收集、最短存储 |
| 《算法推荐管理规定》 | 第18-19条 | 不得利用算法诱导未成年人沉迷 |

---

## 数据分类与收集原则

### 允许收集（最小必要）

| 数据项 | 必要性 | 用途 | 保留期限 |
|:--|:--|:--|:--|
| 省份 | 必需 | 适配高考模式和录取规则 | 永久（至账号注销）|
| 高考成绩/排名 | 必需 | 院校推荐的核心依据 | 当年高考季结束 |
| 选科组合 | 必需 | 匹配专业限制 | 当年高考季结束 |
| 意向专业大类 | 可选 | 个性化推荐 | 永久（至账号注销）|
| 对话内容 | 自动生成 | 提供连续咨询服务 | 30天后匿名化 |

### 禁止收集

| 数据项 | 原因 |
|:--|:--|
| 真实姓名 | 非必要，且涉及 PII |
| 身份证号 | 敏感个人信息，非必要 |
| 学校全名 | 可能用于识别个人身份 |
| 家庭住址 | 敏感个人信息，非必要 |
| 家庭收入 | 敏感个人信息，可能用于歧视 |
| 面部信息/生物特征 | 无任何业务需要 |

### 用户主动提供的隐私信息

```yaml
# 当用户在对话中主动透露隐私信息时的处理规则
handling_user_disclosed_pii:
  detection:
    - '手机号：正则 1[3-9]\d{9}'
    - '身份证号：正则 [1-9]\d{5}(19|20)\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\d|3[01])\d{3}[\dXx]'
    - '学校全名：匹配已知学校库（3003所）的完整校名'
    - '地址：匹配省市区+具体地址模式'

  response: |
    温和提醒：在跟 AI 聊天时，不用告诉我你的{具体信息类型}，
    我只需要知道你的省份和分数就能帮你分析。
    记得保护好自己的个人信息哦。

  storage: '不存储、不记录、不传给任何第三方'
```

## 未成年人保护机制

### 年龄判定

```yaml
age_verification:
  method: '实名认证（对接运营商二要素验证）'
  # 不强制实名时的替代方案
  fallback:
    - '注册时选择年龄段（<14 / 14-17 / 18+）'
    - '行为特征推断（语气、问题类型、活跃时段）'

  age_groups:
    under_14:
      protection_level: '最高'
      requirements:
        - '需要监护人同意（PIPL 第31条）'
        - '注册流程中展示监护人同意书'
        - '监护人可查看对话记录摘要'
      14_to_17:
      protection_level: '增强'
      requirements:
        - '可以自主使用，但展示增强保护提示'
        - '开启防沉迷机制'
        - '检测到心理危机时自动通知紧急联系人'
    18_plus:
      protection_level: '标准'
      requirements:
        - '正常服务流程'
```

### 防沉迷机制

```yaml
anti_addiction:
  # 单次会话限制
  single_session:
    warning_at: 40  # 分钟
    limit_at: 45    # 分钟，提示休息
    force_break_at: 60  # 分钟，强制结束会话
    break_message: |
      你已经连续聊了{分钟}分钟了，
      高考备考也要注意休息。
      去喝杯水、活动一下吧，我随时都在。

  # 每日累计限制
  daily_limit:
    warning_at: 90   # 分钟
    limit_at: 120    # 分钟
    limit_message: |
      今天已经聊了{分钟}分钟了，
      合理分配时间也很重要。
      明天再来，我会继续帮你。

  # 休息提醒
  rest_reminder:
    interval: 20  # 每 20 分钟提醒一次
    message: '休息一下眼睛吧，你的眼睛比志愿更重要 👀'

  # 深夜限制（23:00 - 06:00）
  night_mode:
    start: '23:00'
    end: '06:00'
    message: |
      现在已经很晚了，好好休息才能有更好的状态。
      明天白天再来，我随时帮你。
    allow_override: false  # 不可跳过
```

### 心理危机升级机制

```yaml
crisis_escalation:
  # 当检测到 Level 2+ 危机信号时
  level_2_plus:
    actions:
      - '立即展示心理援助热线（见输出安全过滤模板 Step 3）'
      - '记录危机信号（脱敏后）供后续分析'
      - '如果用户在 5 分钟内未回复 → 再次展示热线信息'

  # 如果用户提供了紧急联系人
  emergency_contact:
    trigger: 'Level 3 危机信号 + 用户设置了紧急联系人'
    action: '通过预设渠道通知紧急联系人（短信/微信模板消息）'
    template: '您设置的紧急联系人在使用高考志愿助手时可能需要心理支持，建议您关注一下。'

  # 对话内容中的危机检测关键词
  # （与输出安全过滤模板 Step 3 共享，此处不重复）
```

## 数据存储与处理安全

```yaml
data_security:
  # 存储加密
  at_rest:
    algorithm: 'AES-256-GCM'
    key_management: '独立密钥管理服务（KMS）'
    scope: '所有用户数据（对话记录、用户画像、会话元数据）'

  # 传输加密
  in_transit:
    protocol: 'TLS 1.3'
    certificate: 'OV 级别以上 SSL 证书'

  # 外部 API 调用时的脱敏
  api_calls:
    to_llm_provider:
      strip_pii: true
      method: '调用前用正则 + NER 模型双重检测'
      replace_with: '[已脱敏]'
    to_third_party:
      rule: '绝不向第三方发送任何可识别用户身份的信息'

  # 数据保留与自动删除
  retention:
    conversation_logs: '30 天 → 自动匿名化'
    user_profiles: '保留至用户主动注销'
    analytics_data: '90 天 → 聚合为统计数据后删除明细'
    crisis_records: '保留 1 年（安全合规需要）→ 删除'

  # 用户数据删除权（PIPL 第47条）
  deletion:
    trigger: '用户在界面点击"删除我的数据"'
    scope: '所有数据存储（主库 + 缓存 + 日志 + 向量库）'
    timeline: '72 小时内完成删除'
    confirmation: '删除完成后发送确认通知'
```

## 隐私政策要点（供法律文本参考）

```yaml
privacy_policy_outline:
  必须包含:
    - '收集哪些信息、为什么收集'
    - '信息如何使用（仅用于高考志愿咨询服务）'
    - '信息存储在哪里、保留多久'
    - '信息是否与第三方共享（不共享，除非法律要求）'
    - '用户权利（查阅、更正、删除、撤回同意）'
    - '未成年人保护措施'
    - '投诉举报渠道'
    - '政策更新通知方式'

  语言: '简体中文，通俗易懂，避免过度法律术语'
  展示时机:
    - '首次使用前（必须阅读并同意）'
    - '每次重大更新后重新获取同意'
    - '设置页面可随时查看'
```

## 在 System Prompt 中的嵌入指令

```
【隐私保护 - 不可覆盖】
1. 当用户主动提供个人隐私信息（姓名、身份证、手机号、详细地址）时，
   不要存储或复述这些信息，温和提醒用户注意隐私保护。

2. 如果用户问"你记得我叫什么/我的身份证号是什么"，
   回答"我不会记录这些个人信息，我只需要知道你的省份和成绩就好"。

3. 推荐建议中不要包含任何可识别个人身份的信息。
```
