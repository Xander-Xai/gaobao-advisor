# G1 志愿填报核心方法（合成演示）

> SYNTHETIC_DEMO 合成演示知识：以下规则、术语与流程均为本仓库原创编写的虚构示例，
> 不对应任何真实省份的招生政策，不可用于真实志愿填报决策。

## 志愿填报方法

志愿填报的核心是"分数 / 位次 → 可报范围 → 排序取舍"三步。先确定自己在
全省的位次（而不是绝对分数），再用位次去对照目标院校近年（合成示例中仅
保留一个演示年份）的录取位次区间，最后在可报范围内按个人偏好排序。

合成演示流程可以概括为：

1. 用一分一段把分数换算为位次；
2. 按位次圈定"冲、稳、保"三档候选；
3. 在每一档内按专业意愿、城市偏好和学费承受度排序；
4. 检查是否有单科要求、身体条件或选科限制等硬性门槛。

## 平行志愿规则（合成示例）

在合成示例规则中，平行志愿遵循"分数优先、遵循志愿、一次投档"的原则：
系统按考生位次从高到低依次检索，对每位考生按其填写的志愿顺序检索，
一旦投档即不再检索后续志愿。

合成示例强调两个容易误解的点：

* 平行志愿的"平行"只体现在**检索机会**上，真正投档时志愿顺序仍然重要；
* 是否服从调剂会显著影响退档风险，即使在平行志愿批次也一样。

## 冲稳保策略

冲稳保是把候选院校按录取概率分成三档的排序方法：

* **冲**：录取位次略高于自己位次的院校，数量不宜过多；
* **稳**：与自己位次大体匹配的院校，通常是主力；
* **保**：录取位次明显低于自己位次的院校，用于兜底。

合成示例建议的比例是"少量冲、多数稳、必须有保"，具体比例因省份批次
规则不同而不同，应以当年官方志愿表结构为准。

## 风险提示

合成示例中列出三类常见风险：

* **滑档**：所有志愿都高于自身位次，无法投档；
* **退档**：已投档但因不服从调剂、单科不达标或身体条件等原因被退回；
* **顺序误判**：把真正想去的志愿填在靠后位置，导致被前面志愿录取。

风险管理的基本做法是确保"保"档真实可录取，并认真阅读招生章程中的硬性条款。

## 咨询表达原则

合成示例的咨询风格要求是：把复杂规则翻译成可执行的步骤，先确认事实
（省份、位次、选科），再给排序建议，并明确区分"已知数据"与"待核实信息"。
