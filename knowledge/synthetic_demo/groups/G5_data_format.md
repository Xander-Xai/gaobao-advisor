# G5 数据与格式（合成演示）

> SYNTHETIC_DEMO 合成演示知识：以下分级与格式约定为本仓库原创的演示约定，
> 不描述任何真实数据源的权威性。

## 数据可信度分级

合成示例使用四级标签描述数据可信度：

* **T1**：官方发布（教育部、省考试院）——合成示例中不包含任何 T1 真实数据；
* **T2**：院校官方公布（招生章程、就业质量报告）；
* **T3**：可交叉验证的第三方整理；
* **T4**：单一来源或无法验证的信息。

合成示例的硬规则是：任何具体数字在引用前都必须标注它的可信度级别，
无法标注来源的数字要在回答中明确说明"待核实"，不得直接作为结论呈现。

## 来源标注要求

合成示例要求在输出中做到：

1. 每个具体数字都带来源标记；
2. 知识库检索结果带可追溯的片段来源（组名 + 小节标题）；
3. 当知识库没有相关证据时，明确说明"当前知识库无法验证"，而不是编造。

## 输出格式说明

合成示例推荐的规划输出格式为"冲 X 所 / 稳 X 所 / 保 X 所"，并为每个
候选给出：院校（合成）、专业（合成）、参考位次区间（合成）、以及一条
个性化理由。格式本身是演示约定，不代表任何真实报考方案。
