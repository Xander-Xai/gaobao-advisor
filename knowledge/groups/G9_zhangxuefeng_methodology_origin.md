# G9 张雪峰方法论溯源（WHY）

> **本模块用途**：RAG 知识源。当用户提问涉及"张雪峰""为什么这么说""张雪峰的方法论"时，自动召回。本模块不替代 G1-G8 的方法论，而是补充**方法论的来源、出处、行为模式、争议与盲点**。

## 9.1 核心论点的书籍溯源

| 核心论点 | 出处 | 张雪峰表达方式 |
|---------|------|--------------|
| 选择 > 努力 | 《方向比努力更重要》（2021） / 《选择比努力更重要》（2021/2023修订） | 反复在讲座直播中强调：方向错误的努力是浪费 |

## 9.2 行为模式（从外部视角观察）

> 注：以下"他"指代张雪峰。本知识组被注入 LLM 时,目的是供顾问"了解他的思维",而非"模仿他说话"。

### 模式一：「争议即流量」循环
- 表现：极端言论 → 舆论争议 → 全网讨论 → 流量暴涨 → 商业变现
- 案例：2023 年关于新闻学的极端否定言论 → 志愿填报服务爆卖；2023 年关于文科的争议表述 → 道歉后热度不减
- 解读：争议是商业模式的有机组成，但也是健康代价的来源

### 模式二：「认态度不认事实」道歉策略
- 涉及核心观点（专业选择要就业）→ 绝不道歉，只补语境
- 涉及表达方式（措辞不当）→ 愿意道歉
- 涉及平台规则 → 完全配合

### 模式三：「言出必行」的转型决策
- 2007 北漂做考研辅导 → 2016 抓短视频 → 2021 转型高考志愿 → 2024 跨界创投
- 每次业务扩张都紧跟时代趋势，行动果断

## 9.3 思维盲点（外部批评视角，**反向校验用**）

| 盲点 | 来源 | 校检作用 |
|------|------|----------|
| **自我矛盾**：自己是"给排水→考研辅导→教育博主"的成功跨界，恰恰是"专业不重要"的活证据 | 钛媒体/三联 | 当我们过度强调"专业定终身"时，应回看这个反例 |
| **预判能力局限**：早年曾推荐过新闻学，后来改口劝退 | 维基百科 | 提醒我们任何"绝对结论"都有时间局限 |
| **信息差悖论**：当所有人都按"就业好"专业填报时，反而造成新内卷 | 21经济网 | "热门专业"本身会变冷，要看周期 |
| **绝对化思维**：将复杂选择简化为硬规则，忽略个体差异 | 学术界批评 | 复杂案例需启用"高审慎"模式（见 G1.3）|

## 9.5 价值观形成时间线

```

  ↓

  ↓

  ↓

  ↓
```

## 9.6 与 G1-G8 协同规则

- **G1 核心方法论**："做什么"（5 心智模型、8 启发、8 反模式）
- **G9 本模块**："为什么"（方法论的来源、出处、行为模式、盲点）
- **当用户问**"张雪峰说的对吗" → 优先召回 G9.3 盲点 + G9.2 行为模式
- **当用户问**"张雪峰怎么选专业" → 召回 G9.1 核心论点 + G1.3 家庭背景矩阵
- **当用户问**"张雪峰经历" → 召回 G9.4 决策时间线 + G9.5 价值观形成
- **当用户问**"张雪峰金句" → 走金句 RAG（`zhangxuefeng_originals.json` 50 句）而非 G9

## 9.7 使用边界（重要）

- **G9 内容均基于张雪峰生前公开言论和权威媒体报道**（2026-03-24 去世）
- **不模拟张雪峰身份说话**——本项目保留"老规划师"人设，张雪峰金句仅作为引用素材
- **引用 9.3 盲点时需谨慎**——避免直接对用户说"张雪峰错了"，改为"这个观点也有反面案例……"
- **时间敏感性**——任何"张雪峰说过"的引用都应附带时间戳（见 9.4 决策时间线）
