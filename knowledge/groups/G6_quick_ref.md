# G6 速查手册

## 十二、高考志愿填报要点速查

### 12.1 新高一选科指南（3+3 / 3+1+2）

| 组合 | 特点 | 建议 |
|------|------|------|
| 物化生 | 纯理组合，覆盖率最高 | 理科生首选 |
| 物化政 | 专业覆盖率最高，学习难度大 | 主科不瘸腿可选 |
| 物化地 | 临床/生物类专业可报，地理赋分有优势 | 中等生不错选择 |
| 物生政 | 公安类/中医类专业可报 | 特定方向 |
| 史政地 | 纯文组合，赋分有优势 | 文科方向 |
| 史政生 | 比纯文多护理类专业 | 女生不错选择 |
| 史地生 | 学习难度相对低 | 保本/冲分 |
| 史化生 | 学科关联度弱 | 不太建议 |

### 12.2 根据优势学科选专业

| 优势学科 | 推荐专业方向 |
|---------|------------|
| 语文好 | 师范类、新闻传播类、中国语言文学类 |
| 数学好 | 师范、数学、财会、计算机、统计学、心理学、经济学、金融学、电子信息 |
| 英语好 | 师范类、外国语言文学类、经济贸易类 |
| 政治好 | 师范、哲学、法学、政治学、经济学、社会学、公共管理、马克思主义理论 |
| 物理好 | 师范、物理学、力学、电子信息、自动化、计算机、电气、机械、土木、航空航天、兵器、核工程、材料 |
| 化学好 | 师范、医学、化学、医技、动物医学、化工制药、核工程、材料、食品科学 |
| 生物好 | 师范、生物科学、生物工程、医学、农学 |
| 地理好 | 师范、气象学、测绘、水利水电、城市规划、地质勘探、旅游 |

### 12.3 大学报志愿18个要点

1. 普通家庭 → 军校、警校
2. 家庭富裕 → 金融、经济、经管
3. 高薪就业 → 名校计算机、电子通信
4. 人工智能、大数据 → 非名校不要选
5. 非名校 → 不要选经管
6. 生化环材 → 不硕博不碰
7. 农林/建土/地矿/石油/地信 → 经常风餐露宿
8. 艺术 → 费钱费毕业，没实力不要碰
9. 医学法学 → 又苦又累，没有硕博难就业
10. 金融 → 不能碰（除非家里搞金融）
11. 管理类 → 不要碰（除非家里有企业需要管）
12. 想考公 → 优先选汉语言文学和思政，不要选英语
13. 想当医生 → 在哪儿当医生就读哪儿的医学院
14. 文科优先选学校，理工科优先选专业
15. 城市有时候比学校更重要
16. 工科比理科挣钱多
17. 数学、计算机专业都很好
18. 了解上大学的目的，是为了以后的就业生存

### 12.4 大学四年最佳安排

| 年级 | 建议 |
|------|------|
| 大一 | 申请入党、考驾照、普通话证 |
| 大二 | 学生会、计算机二级、英语四六级 |
| 大三 | 准备考研、考教师资格证 |
| 大四 | 考研、选调生、考编公务员、央企国企校招 |

| 方向 | 路径 |

| **进部队** | 军校、军士、文职、直招军官/军士 |

| **央国企** | 电网、烟草、铁路、石油、水利、电信、航空、航天、军工、民航 |
| **当医生** | 临床、口腔、眼科、麻醉、儿科、影像、法医、药学、护理、检验、针灸、康复 |
| **拿高薪** | 口腔、律师、医美、金融、航海、飞行、电商、互联网 |
| **大趋势** | 人工智能、自动驾驶 |
